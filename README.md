# AI-ChatBot
An AI-powered chatbot built using HTML, CSS, and JavaScript with support for text conversations and image input using the Google Gemini API.

🚀 Features
💬 AI-powered chat interface
🖼️ Image upload support
📱 Responsive design
⚡ Fast and simple UI
🤖 Gemini API integration
🔄 Loading animation while generating responses
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Google Gemini API
📂 Project Structure
AI-ChatBot/
│── index.html
│── style.css
│── script.js
│── ai.png
│── user.png
│── image.png
│── loading.png
│── README.md

Replace:

const API_KEY = "YOUR_API_KEY";

with your own Google Gemini API key.

Run the project by opening index.html in your browser or using the VS Code Live Server extension.
🔑 Getting a Gemini API Key
Open Google AI Studio.
Create a new API key.
Copy the API key.
Replace YOUR_API_KEY in script.js with your own key.

Important: Never commit or upload your real API key to GitHub.
